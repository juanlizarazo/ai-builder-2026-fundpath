# Government Opportunity Finder — Deep Research Reference (GOEO "Startup State" Challenge, Aug 14 2026)

## TL;DR
- **All four recommended data sources are usable inside 24 hours, but only two are auth-free.** Grants.gov Search2/fetchOpportunity (no key) and USAspending v2 (no key) can be hit immediately; SAM.gov Assistance Listings requires a SAM.gov API key (and a profile associated with an entity to escape a hard **10 requests/day** cap); SBIR.gov's API has intermittent maintenance outages, so mirror it to CSV early.
- **The killer feature is honest matching plus a cross-source join on the ALN/CFDA number**, which links a Grants.gov opportunity → SAM.gov Assistance Listing (eligibility/obligation history) → USAspending awards (who actually got paid) → SBIR.gov (named similar firms). Eligibility is where most matches should be *rejected*: most Grants.gov opportunities are restricted to states/nonprofits/universities, and SBIR requires for-profit, ≤500 employees, ≥51% US‑individual ownership.
- **Test case 5 (youth-activities marketplace) is the abstention trap:** there is essentially no strong federal grant fit; the one real edge case is ED/IES SBIR (education technology, and only with a genuine R&D/research core), and the honest recommendation set is SBA 7(a)/microloans, Utah SSBCI, and local economic development — not fabricated grants.

## Key Findings
- Grants.gov Search2 is a POST to `https://api.grants.gov/v1/api/search2`, no auth, JSON body; `fetchOpportunity` returns full detail. Filters include `keyword`, `oppNum`, `eligibilities`, `agencies`, `oppStatuses`, `fundingCategories`, `fundingInstruments`, `aln`, `rows` (max 1000), `startRecordNum`.
- SAM.gov Assistance Listings API (`https://api.sam.gov/assistance-listings/v1/search`) needs an `api_key`; per the GSA Federal Service Desk article KB0017604 (last updated 17 March 2026), "For non-federal users, there is a rate limit of 10 requests per day. You can obtain a rate limit of 1000 per day if your profile is associated with an entity." It returns eligibility applicant/beneficiary type codes, obligation history, and range/average award amounts — the richest eligibility data of any source.
- USAspending `POST /api/v2/search/spending_by_award/` requires `award_type_codes` in filters plus `sort`+`order`; grant codes are 02/03/04/05, contracts A/B/C/D, loans 07/08. Practical cap ~10,000 records per query; bulk download via `POST /api/v2/download/awards/`.
- **SBIR was reauthorized April 13, 2026** — President Trump signed the **Small Business Innovation and Economic Security Act of 2026 (S. 3971)**, extending SBIR and STTR **through September 30, 2031** (Senate passed by voice vote Mar 3, 2026; House 345–41 Mar 17, 2026), after the previous authorization expired September 30, 2025. Per SBIR.gov's official "About SBIR and STTR" page, "As of April 2026, agencies may issue a Phase I award (including modifications) up to **$323,090** and a Phase II award (including modifications) up to **$2,153,927** without seeking SBA approval." The Act also introduced a new Phase II **"strategic breakthrough" funding vehicle with a $30 million ceiling** for agencies whose annual required SBIR expenditures exceed $100 million (capped at 0.5% of that agency's required expenditures).
- Utah has an unusually strong SBIR support ecosystem: Utah Innovation Center (now Nucleus), an SBA FAST awardee, plus UTIF microgrants ($3,000) and non-recourse bridge loans, and SSBCI (~$69M). The SBIR/STTR programs collectively have "fueled over $70 billion in small business–led R&D" since 1982 (MNSBIR, Apr 2026).

## Details

### 1. DATA SOURCES — HANDS-ON

#### 1a. Grants.gov Search2 + fetchOpportunity (BEST first source; no key)
- **Endpoints:** Production `https://api.grants.gov/v1/api/search2` and `https://api.grants.gov/v1/api/fetchOpportunity`; staging `https://api.staging.grants.gov`. Method: **POST**, `Content-Type: application/json`. **No authentication/API key required** for these two (confirmed on the official API Guide and the March 2025 Grants.gov announcement of the two new RESTful APIs). Note: other Grants.gov REST services — e.g., the grantor "Opportunity Totals by CFDA" service — DO require an API key from the Help Desk; only search2/fetchOpportunity are open.
- **Search2 request body fields (all optional, combine freely):**
  - `keyword` (string)
  - `oppNum` (opportunity number)
  - `eligibilities` (applicant-type codes, comma-separated — see §5)
  - `agencies` (agency codes, e.g., `HHS`, `HHS-NIH11`)
  - `oppStatuses` — `forecasted`, `posted`, `closed`, `archived`; combine with pipe `closed|archived`. `posted` = currently open.
  - `fundingCategories` — two-letter codes (e.g., `HL` Health, `ST` Science/Tech/R&D, `ENV` Environment, `ED` Education).
  - `fundingInstruments` — `G` Grant, `CA` Cooperative Agreement, `PC` Procurement Contract, `O` Other.
  - `aln` (Assistance Listing Number / CFDA, e.g., `93.866`). **Gotcha:** a well-documented community wrapper (`christopherBelter/gov_opps_api`) states "The API currently ignores this parameter, so use the cfda instead" — verify against live behavior and be prepared to post-filter on ALN client-side.
  - `sortBy`, `rows` (max **1000**), `startRecordNum` (pagination offset).
- **Response:** JSON with `data.oppHits[]` (each has `opportunityId`, `opportunityNumber`, `opportunityTitle`, `agencyName`, `openDate`, `closeDate`, `estimatedFunding`/`oppStatus`), plus paging fields (`hitCount`, `startRecord`). To get full detail (eligibility text, description, attachments) call **fetchOpportunity** with the opportunity id (`data.oppHits[].id`).
- **Example body:** `{"fundingCategories":"HL","agencies":"HHS","oppStatuses":"forecasted","aln":"93.866"}` or simply `{"keyword":"health"}`.
- **Reliability/known gotchas:** stable, but the session-protected HTML site (not the API) throws 3-minute timeout modals; the legacy SOAP System-to-System suite still exists but the RESTful pair is the modern path. Existing wrappers to leverage: `christopherBelter/gov_opps_api` (R), `jhalsey87/MCP_Grants_Search` and BioContextAI Knowledgebase MCP (Python), dltHub Grants.gov source.

#### 1b. SAM.gov Assistance Listings (Federal Assistance Listings; needs key)
- **Endpoint:** Production `https://api.sam.gov/assistance-listings/v1/search`, Alpha `https://api-alpha.sam.gov/assistance-listings/v1/search`. Method **GET**, `api_key` as query param.
- **API key:** Any SAM.gov account can generate a **personal/public API key**. Per the GSA Open Technology docs: obtain it at `https://sam.gov/profile/details` — "Click on the 'Eye' icon, enter the 'Enter One-time Password' (this value will be sent to your email address...), hit 'Submit', for the API Key value to appear in the box." The key itself is instant once you have an account. **CRITICAL 24-HOUR RISK:** a non-federal user whose profile is **not associated with an entity** is limited to **10 requests/day**; associating your profile with an entity raises it to **1,000/day**, and only federal system-account users can request further increases. Entity association can take days — so for a hackathon, either (a) pre-register a SAM.gov account tonight and generate the key immediately, or (b) avoid the key entirely via bulk data.
- **Key-free alternative:** Assistance Listings are published as **annual PDF catalogs back to 2008** and as **bulk data extracts** on SAM.gov Data Services; the CSV/JSON extract can return up to 1,000,000 records. GSA replaced the annual CFDA catalog publication with this API. If the key is a blocker, ingest a bulk extract once and query locally.
- **Request params:** `pageSize` (max 1000), `pageNumber` (0-based), `status` (Active/Inactive/All), `assistanceListingId` (e.g., `93.866`), `assistanceTypes[]` (F001 Grant, F002 Cooperative Agreement, F003 Direct Loan, F004 Loan Guarantee, F006 Direct Payment specified use, etc.; N-codes are non-financial), `applicantTypes[]`, `beneficiaryTypes[]`, `organizationCodes[]` (FPDS dept/agency codes), `organizationLevel`, `publishedDateFrom/To`, `coreBasedStatisticalDelineations`.
- **Response richness (the reason to use it):** per listing — `assistanceListingId`, `title`, `federalOrganization` (dept/agency/office + codes), `overview.objective`, `financialInformation.obligations[].values[]` (actual/estimate by year — historical spend), `rangeAndAverageAssistance[]` (min/max/avg award by FY), and **`criteriaForApplying.applicant.types[]`** with entity-type codes (ET-codes) + free-text `description`, plus `assistanceUsage`/`assistanceRestriction`. The applicant-type codes (e.g., **ET41030 For-Profit Organization**, **ET51120 Small Business Person**, **ET22010 U.S. State Government**, **ET41010 Nonprofit Organization**) are the machine-readable eligibility signal for the "what could make you ineligible" panel.
- **Volumes:** ~2,200+ active assistance listings (CFDA programs). Full OpenAPI spec at `open.gsa.gov/api/assistance-listings-api/v1/assistance-listings-api.openapi.yaml`.

#### 1c. USAspending.gov API v2 (award intelligence; no key)
- **Base:** `https://api.usaspending.gov`; docs at `/docs/endpoints`. No key, generous limits, but paginated search tops out ~10,000 records/query (use bulk download beyond that).
- **Primary endpoint:** `POST /api/v2/search/spending_by_award/`. Body needs a `filters` object (must include `award_type_codes`), a `fields` array, and **required** `sort` + `order` (omitting them → 400 with a list of valid sort keys). Field names on this endpoint are **capitalized/spaced** ("Recipient Name", "Award Amount", "Recipient UEI") — using snake_case silently drops the field with no error.
- **Award type codes:** Contracts A/B/C/D; IDVs IDV_*; Loans 07/08; Grants 02/03/04/05; Direct payments 06/10; Other 09/11/-1. **To find SBIR/STTR:** most are either contracts (DoD, NASA — codes A–D) or grants (NSF, NIH — 02/04/05); there is no single "SBIR" flag, so filter by NAICS/PSC + recipient + agency and/or keyword, then dedupe against SBIR.gov.
- **Useful filters:** `recipient_search_text`, `recipient_locations` (state), `place_of_performance_locations`, `agencies[]` (awarding/funding × toptier/subtier), `naics_codes[]`, `psc_codes[]`, `time_period[]`, `award_amounts[]` (lower/upper bound), `program_activities`, `def_codes`.
- **Other endpoints:** `/api/v2/search/spending_by_award_count/` (counts by type), `/api/v2/search/spending_by_category/` (group by recipient/agency/geo — good for "who else got this money" leaderboards), `/api/v2/awards/{generated_internal_id}/` (full record, 26+ top-level + nested `latest_transaction_contract_data` with 69 contract fields), `/api/v2/recipient/`, and bulk `POST /api/v2/download/awards/`.
- **Example:** `{"filters":{"recipient_search_text":["Lockheed Martin"],"award_type_codes":["A","B","C","D"],"time_period":[{"start_date":"2024-01-01","end_date":"2026-12-31"}]},"fields":["Award ID","Recipient Name","Recipient UEI","Award Amount","Start Date","Awarding Agency"],"sort":"Award Amount","order":"desc","page":1,"limit":100}`.
- **Gotchas:** classified/national-security contracts are absent (not in FPDS); "Award Amount" is often the ceiling while obligations are what's actually committed; obligations ≠ cash disbursed. Server app is open source: `fedspendingtransparency/usaspending-api` (the `api_contracts` markdown is the best schema reference).

#### 1d. SBIR.gov API + data files (named-competitor intelligence)
- **Base:** `https://api.www.sbir.gov/public/api/`. Three datasets: **awards**, **solicitations** (topics), **firms/companies**. Legacy host `legacy.www.sbir.gov/api/`. **Reliability warning:** the SBIR.gov APIs have posted "currently undergoing maintenance" notices in 2025–2026 — ingest CSVs early and cache; don't depend on live calls during the demo.
- **Awards endpoint:** `…/awards?agency=…&year=…&rows=400&start=…` (default 100 rows/page, offset pagination via `start`). Fields: `firm, award_title, agency, branch, phase, program, agency_tracking_number, contract, proposal_award_date, contract_end_date, solicitation_number, solicitation_year, topic_code, award_year, award_amount, duns, uei, hubzone_owned, socially_economically_disadvantaged, women_owned, number_employees, company_url, address1/2, city, state, zip, poc_*, pi_*, ri_* (research institution), research_area_keywords, abstract, award_link`. **Filter Utah via `state`.**
- **Solicitations/topics:** `…/solicitations?keyword=…&format=json|xml` — Open/Future/Closed status; includes `solicitation_topics` → `topic_title, branch, topic_number, topic_description, sbir_topic_link, subtopics[]`. Default 25 rows, `rows` param to increase.
- **Companies:** `…/firm?uei=…` or `?start=…` — `firm_nid, company_name, sbir_url, uei, duns, address, company_url, hubzone_owned, socially_economically_disadvantaged, woman_owned, number_awards`.
- **Bulk:** downloadable award files in XLS/CSV/JSON/XML from the Data Resources page; a Data Dictionary defines fields (note API fields differ slightly from download fields). The award file is large (SBIR/STTR have generated over $70B in R&D since 1982; a widely cited figure is 180,000+ awards) — filter by state/agency/year on ingest.

### 2. TRANSLATION LAYER — HOW SBIR/STTR & FEDERAL FUNDING ACTUALLY WORK

**Three phases:** Phase I = feasibility (6–12 months; NIH allows up to 2 yrs); Phase II = full R&D/prototype (≈24 months, Phase I awardees only, except Direct-to-Phase-II); Phase III = commercialization, **no SBIR funds, no competition requirement, and the basis for sole-source federal contracts** (data rights protected 20 years after a Dec 2024 DoD final rule).

**FY2026 award sizes (post-April-13-2026 reauthorization; statutory ceilings $323,090 Phase I / $2,153,927 Phase II per SBIR.gov, most agencies set limits lower):**
- **NIH (SEED):** highest ceilings — Phase I up to ~$323,090, Phase II up to ~$2,153,927 before waiver topics; omnibus solicitation + institute-specific PAs; standard due dates (historically Jan 5 / Apr 5 / Sep 5); budget waivers common above guideline; NIH opts into the majority-VC track.
- **NSF (America's Seed Fund):** Phase I **$305,000** (6–18 mo), Phase II up to **$1,250,000** (24 mo), Fast-Track up to ~$1,555,000 ($400K + $1,155K); **mandatory Project Pitch** before an invited full proposal; issued as **grants, not contracts**; per BW&CO, "Project Pitch submissions begin June 2, 2026," with full Phase I/Fast-Track proposals due 11/04/2026; NSF expects a ~$25K I-Corps line in Phase I budgets; open to virtually any deep-tech area; Phase I funding rates ~10–20%.
- **DoD (AFWERX/SpaceWERX etc.):** Phase I often **$75K–$295K** (AFWERX Open Topic ~$75K SBIR / $110K STTR), Phase II up to **$1.8–2M**; **open topics** (company proposes the problem; requires a named government end-user/customer memo) vs **conventional topics** (program office defines the requirement — primes cannot submit topics directly); Direct-to-Phase-II (D2P2) up to $1.25M; **STRATFI/TACFI** bridges ($3–15M SBIR + government/private match, packages up to ~$60M). Rolling windows via DSIP; recent AFWERX/SpaceWERX closes cited 08/19/2026 & 09/23/2026. The reauthorization expands D2P2 into STTR and adds the $30M Strategic Breakthrough track.
- **NASA:** FY2026–2027 BAA active through 09/30/2027; contracts; Phase I ~6 months.
- **DOE:** Phase I ~$200K; Phase I and select Phase II opportunities expected summer 2026.
- **DHS S&T:** smaller program; cyber/OT/AI-threat-detection topics; "Phase 0" support for first-timers.
- **ED/IES:** Phase I $250K/8mo, Phase II $1M/2yr (older cycles $200K/$900K); annual fall solicitation; D2P2 available. IES awarded 26 SBIR projects in 2025 (16 Phase I, 8 Phase II, 2 D2P2).

**Eligibility rules (surface these):** for-profit; **≤500 employees including affiliates** (13 CFR 121.103 affiliation — VC portfolio companies under common control can aggregate over 500!); **≥51% owned and controlled by US citizens/permanent-resident individuals** — or by another qualifying small business. Majority-VC/PE/hedge-fund ownership is allowed **only at agencies that opted into §5107 authority** — in practice **NIH and NSF** (and per a 2022 GAO finding, only DoD and HHS regularly awarded to VC-backed firms). **STTR** is stricter: requires a **research-institution partner** (≥30% of work to the RI, ≥40% to the small business) and the PI may be employed by the RI; **SBIR** requires the PI **primarily employed (>50%) by the small business**. Eligibility is certified **at time of award**, not application.

**Registration prerequisites & lead times (practical insight for "what to do next"):** SAM.gov **UEI** (allow **10–15 business days, budget 3–4 weeks** if document issues) → SBA Company Registry (SBIR.gov) → Grants.gov → agency systems (NIH **eRA Commons**, DoD **DSIP**, NSF Research.gov). These lead times are the single most common reason startups miss a deadline.

**Non-SBIR federal programs by vertical:**
- **Healthcare:** ARPA-H SBIR/STTR BAA (Phase I / D2P2 / Fast-Track, topic-specific; a 2026 draft lists Solution Summary due July 10, 2026, with per-topic amounts up to multi-$M); AHRQ (R18 demonstration ~$400K direct/yr for up to 3 yrs; patient-safety/AI-safety and administrative-burden focus); NIH institutes (R21 exploratory up to ~$275K direct/2yr, R33 development up to ~$1M direct/3yr; R01); CMS/ONC health-IT.
- **Advanced manufacturing/aerospace:** NASA SBIR "In-Space & Advanced Manufacturing" and Advanced Manufacturing Technologies (metallic joining, additive, composites, lightweight metals); **Manufacturing USA** institutes; **NIST MEP** (small-manufacturer extension, incl. aerospace supply chain and cybersecurity); **DOE AMMTO** (Advanced Materials & Manufacturing Technologies Office) and IEDO; **DoD ManTech**; DoD SBIR aerospace topics.
- **Water/climate:** EPA SBIR + Clean Water/Drinking Water SRF + WIFIA (infrastructure loans, large borrowers); **Bureau of Reclamation WaterSMART** (Water & Energy Efficiency Grants — 50/50 cost-share; Applied Science Grants; Water Strategy Grants; ALN 15.507) and **Reclamation Prize Competitions** (e.g., 2026 "Crack the Case," which selected seven Phase 1 winners at $30,000 each on July 6, 2026; "Halt the Hitchhiker"); **DOE Water Security Grand Challenge** prizes ($1M Water Resource Recovery Prize); USDA rural water; NSF Convergence Accelerator. **Eligibility note:** most Reclamation/EPA water-infrastructure grants require an applicant with **water-delivery authority** (utility/district) or a university partner — a startup usually can't be prime, only a subcontractor/technology provider.
- **Cybersecurity:** DHS S&T SBIR (IoT/OT security, SBOM/supply-chain, AI threat detection — DHS explicitly weighs false-positive rates & SOC deployability); CISA; NSA; DoD SBIR; **NIST NCCoE** (collaborative, in-kind not cash).
- **Consumer/workforce/education:** **ED/IES SBIR** (the real edge case for a marketplace/edtech); DOL WIOA & apprenticeship (grants generally to states/workforce boards, not startups); Dept. of Education discretionary; CDFI Fund; SBA programs; USDA Rural Development.

**Procurement as an opportunity type:** SAM.gov Contract Opportunities (formerly FedBizOpps; note FPDS ezSearch has been retired and its ATOM feed retires later in FY2026, with contract-award search moving into SAM.gov); GSA Schedules / **GSA MAS**; **GSA Startup Springboard** (lets firms <2 yrs use executive experience/financials to get on Schedule); SBA **8(a)**, **HUBZone**, **WOSB/SDVOSB**; **SBIR Phase III sole-source authority**; **OTAs**; **DIU CSO** process; **AFWERX/SpaceWERX**. A startup should realistically know: a Phase II SBIR is the fastest path to a sole-source Phase III contract.

**Non-grant assistance:** SBA **7(a)** (up to $5M) & **504** (fixed-asset), SBA **microloans** (≤$50K), **SSBCI** (state-run), **EDA** (public/nonprofit, not startups directly), USDA loan guarantees.

### 3. UTAH-SPECIFIC PROGRAMS (differentiator)
- **GOEO / Utah Innovation Center (now "Nucleus"):** free SBIR/STTR counseling; Utah cited by GOEO as one of the highest federal-R&D acceptance rates in the US (director Linda Cabrales cites ~15–17% applicant funding rates); SBA **FAST Partnership** awardee.
- **UTIF (Utah Technology Innovation Funding):** **microgrants up to $3,000** (some sources cite $3,000–$5,000) for first-time SBIR/STTR Phase I applicants; **non-recourse loans ~$50K–$60K** for Phase I winners (repay only on commercial success, no interest). Apply via the GOEO portal ≥4 weeks before the federal deadline; eligibility decision within 10 business days; first-come until funds exhausted; proof of submission + proposal due within 90 days.
- **SSBCI (Utah):** ~$69M state allocation, incl. ~$4.1M for <10-employee businesses and ~$8.3M for socially/economically disadvantaged entrepreneurs; plus a **$12M bridge-loan program** (WCF Insurance Foundation among funders).
- **University commercialization:** University of Utah TLO (Ascender Grant $5K–$10K; 1:1:1 MicroGrants), Utah Venture Hub, USU commercialization (e.g., AnalySwift spinout).
- **Other:** EDTIF tax-increment financing, Rural Fast Track, Utah APEX Accelerator (former PTAC, free procurement help), World Trade Center Utah / STEP grants (exporters).
- **Utah SBIR match/bridge:** yes — functionally via UTIF non-recourse bridge loans (repayable only on success), not a pure cash match.

### 4. ELIGIBILITY DISQUALIFIERS TO SURFACE
- Majority foreign ownership (kills SBIR unless restructured); VC/PE >50% (only NIH/NSF, plus DoD/HHS in practice); **affiliate employee aggregation** >500 (VC common-control portfolios under 13 CFR 121.103); PI primary-employment (SBIR) vs RI partnership (STTR); place-of-performance (work in US); prior-award/Phase-II sequencing limits; duplicate-funding prohibition; SAM.gov UEI registration lead time; the 500-employee SBA size standard.
- ARR/raise amounts generally **do not** affect SBIR eligibility (no revenue/profitability test) — a useful "myth-buster" for the UX; but a large single-VC raise can flip eligibility via ownership/affiliation.
- **Programs that exclude for-profits (critical for abstention):** the vast majority of Grants.gov opportunities are restricted to **state/local governments, nonprofits (501c3), and institutions of higher education** (eligibility codes 00–20). A for-profit startup is only cleanly eligible where code **23 (small business)**, **22 (for-profit other)**, or **99 (unrestricted)** appears, or in SBIR/STTR. Water-infrastructure and workforce grants almost always require a government/utility/nonprofit applicant → the correct answer for such matches is "you'd need a municipal or university partner as prime; you can't apply directly."

### 5. DATA/TECHNICAL INSIGHT FOR MATCH QUALITY
- **Grants.gov applicant eligibility codes (search2 `eligibilities`), verified against the official Grants.gov XSD schema:** `00` State governments; `01` County governments; `02` City or township governments; `04` Special district governments; `05` Independent school districts; `06` Public and State-controlled institutions of higher education; `07` Native American tribal governments (Federally recognized); `08` Public housing authorities/Indian housing authorities; `11` Native American tribal organizations (other than Federally recognized); `12` Nonprofits having 501(c)(3) status (other than higher ed); `13` Nonprofits without 501(c)(3) status (other than higher ed); `20` Private institutions of higher education; `21` Individuals; `22` For-profit organizations other than small businesses; `23` Small businesses; `25` Others (see "Additional Information on Eligibility"); `99` Unrestricted. **Codes are non-contiguous — there is no 03/09/10/14–19/24.** (Simpler.Grants.gov uses string tokens instead, e.g., `small_businesses`, `nonprofits`, `unrestricted`.)
- **Funding instrument codes:** `G`, `CA`, `PC`, `O`. **Assistance types (SAM listings):** F001 Grant, F002 Cooperative Agreement, F003 Direct Loan, F004 Loan Guarantee, F006 Direct Payment (specified use), etc.; N001–N007 non-financial.
- **ALN/CFDA join key:** format `##.###`; first two digits = agency (93 = HHS, 47 = NSF, 12 = DoD, 66 = EPA, 84 = ED, 15 = Interior/Reclamation, 10 = USDA, 43 = NASA, 81 = DOE, 97 = DHS). This single field joins Grants.gov opportunity ↔ SAM.gov Assistance Listing (eligibility/obligations) ↔ USAspending awards (recipients). **Build the whole matching graph around it.**
- **NAICS mapping by vertical (verified 2022 titles; for USAspending queries):**
  - AI/SaaS → **541511** Custom Computer Programming, **541512** Computer Systems Design, **513210** Software Publishers (2022 code; was 511210), **518210** Computing Infrastructure/Hosting, **541519** Other Computer Related.
  - Health IT → 541511/541512/513210 + **334510** Electromedical & Electrotherapeutic Apparatus Mfg; R&D under **541714/541715**.
  - Aerospace/manufacturing → **336411** Aircraft Mfg, **336412** Aircraft Engine & Parts, **336413** Other Aircraft Parts & Auxiliary Equipment, **336414** Guided Missile & Space Vehicle, **336415/336419** propulsion/other space-vehicle parts, **326199** All Other Plastics Product Mfg (composites), **541715** R&D.
  - Instruments/sensors → **334511** Search, Detection, Navigation, Guidance, Aeronautical & Nautical Instruments, **334513** Industrial Process Variable Instruments.
  - Water/environmental → **541620** Environmental Consulting, **221310** Water Supply & Irrigation Systems, **221320** Sewage Treatment Facilities, **237110** Water & Sewer Line Construction, **541360** Geophysical Surveying, **541370** Surveying & Mapping, **562910** Remediation.
  - Cybersecurity → **541512** Computer Systems Design (most common primary), **541519** Other Computer Related (SBA IT VAR exception), **541690** Other Scientific & Technical Consulting, **541511**, **561621** Security Systems Services.
  - Relevant PSC: **DA10** (Business Application/App-Dev SaaS), AC/AR-series (R&D), 58-series (comms/detection, maps to 334511), 70-series (IT equipment/software), 5999 (electronic components), **F103** (water-quality support services). **USAspending tip:** filter `recipient_location` State=Utah + NAICS above + award type = Contract (DoD/NASA SBIRs) or Grant/Cooperative Agreement (NSF/NIH SBIRs); SBIR.gov is the cleanest primary source for confirmed SBIR/STTR awards by state.
- **Reusable assets:** SBIR.gov CSV award files; SAM.gov Assistance Listings bulk extract (~2,200 programs); USAspending bulk downloads; open-source wrappers (`gov_opps_api` R, `MCP_Grants_Search`, BioContextAI MCP, dltHub Grants.gov, `fedspendingtransparency/usaspending-api`).
- **Volumes to size ingestion:** ~a few thousand open (`posted`) Grants.gov opps (a third-party "Grant Map" cites 60,000+ across all statuses); ~2,200 assistance listings; 180K+ SBIR awards historically; millions of USAspending records (use filters/bulk).

### 6. COMPETITIVE / STRATEGIC
- **Existing tools:** Instrumentl (~$179–$299/mo; 900K+ funders, pipeline tracking + 990 analysis; nonprofit-oriented, weak on for-profit non-dilutive nuance); OpenGrants (12,000+ users, ~$29/user/mo, Boost VC startup pipeline, hybrid database+consultant marketplace, few independent reviews, ~50K grants); GrantWatch ($199/yr curated); Candid/Foundation Directory (foundations, $39.95/mo); Grantsights / Granted AI / SLED.ai / GrantExec (SBIR-focused content + matching); FindGrants (free tier, 9,000+ open grants + federal contracts). **What they all miss:** honest *ineligibility* reasoning, a cross-source award-history join, and startup-language→gov-language translation with abstention. That gap is exactly the GOEO brief's scoring sweet spot (Intelligence & Insight 20% + Matching 25%).
- **Why startups miss non-dilutive funding:** SBIR Phase I win rates 15–25% (NSF 10–20%), Phase II conversion 40–55%; ~$4B/yr across 11 agencies. SBA policy targets applicant notification within 90 calendar days of solicitation close and award ≤180 days (NSF/NIH slower). Top failure modes: registration lead time and choosing an agency by award ceiling instead of by customer/topic owner and review culture.

HONEST ANSWER: weak/no strong federal grant match — abstain.** There is no federal grant program designed to fund a for-profit consumer marketplace. The system should say so and explain why: (a) most Grants.gov opportunities in this space (DOL WIOA/workforce, ED discretionary, HHS ACF childcare) are restricted to **states, local governments, workforce boards, and nonprofits** (eligibility codes 00–13/20), not for-profit startups; (b) SBIR requires an R&D/technical-innovation core that a booking marketplace typically lacks. **The one legitimate edge case:** **ED/IES SBIR** (Phase I $250K/8mo, Phase II $1M/2yr) — but only if the product has a genuine **education-technology + rigorous-research** component (measurable learning/youth-development outcomes), not merely a marketplace; 2025 ED/IES themes explicitly included workforce-readiness and AI to reduce educator workload. **Honest alternatives:** SBA **7(a)** or **microloan**, Utah **SSBCI** (including the <10-employee and disadvantaged-entrepreneur set-asides), the Utah **$12M bridge-loan** program, local economic-development/EDTIF, WTC Utah/STEP if exporting, and private/venture capital — plus a note that DOL apprenticeship/workforce dollars could reach them only as a **subrecipient** of a state or nonprofit intermediary. ## Caveats
- **SBIR was in flux:** authority lapsed Oct 1 2025 and was reauthorized via **S. 3971, signed April 13, 2026** (through Sep 30 2031). Exact FY2026 solicitation dates/ceilings were still settling — always verify against the live agency solicitation. Sources cite slightly different caps ($305K vs $314K vs $323K) because agency limits sit below the statutory ceiling and because the ceiling itself stepped up in April 2026; treat **NIH ~$323,090/$2,153,927** and **NSF $305,000/$1,250,000** as the anchor figures, and the $30M Strategic Breakthrough track as applicable only to large agencies (>$100M annual SBIR expenditures).
- Grants.gov `aln` filter reliability is uncertain (a documented wrapper says the API ignores it) — verify live and post-filter on CFDA if needed.
- SAM.gov key rate limits (10/day without an entity-associated profile) can silently throttle a demo — pre-provision or use the bulk extract.
- SBIR.gov API maintenance outages are real; cache CSVs.
- USAspending omits classified contracts, and "Award Amount" is often a ceiling, not obligated/disbursed cash.
- Some Utah company details (AnalySwift contract number, RefloDx ~$1M NSF amount, Altaport/XO‑NANO agency/amount) were confirmed secondhand via the Utah GOEO/Nucleus site rather than a primary award record — verify on SBIR.gov/USAspending before publishing inside the product. The cybersecurity vertical has the thinnest set of confirmed pure-cyber Utah-HQ examples; run a live SBIR.gov state=Utah query to strengthen it.
- Dollar amounts, deadlines, and program cycles change with annual appropriations; figures here reflect FY2024–2026 data as of August 14, 2026.
